# Granja Oriche · Propuesta de rediseño

Propuesta de nueva web para [Granja Oriche](https://ponaragonentumesa.com/directorio/sector/productores/huevos-y-aves/granja-oriche/), granja familiar de huevos camperos en Allueva (Teruel).

**No es la web oficial.** Es una maqueta para enseñar a la granja: los precios, días de reparto, formas de pago y fotos están pendientes (aparecen entre `[CORCHETES]` o como huecos).

Web estática: `index.html` + `app.js`. El pedido se envía por email a la granja.
